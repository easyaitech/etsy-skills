# Etsy 文案与商品资料规则入口

上架信息的规则和来源统一由 [关键词与出稿规则](../../../etsy-listing-builder/references/listing-rules.md) 与 [HTML 交付检查](../../../etsy-listing-builder/references/html-delivery.md) 维护，商品定位使用 [产品定义](../../../etsy-product-definition/SKILL.md)。不再使用固定礼赠公式、强制礼物倾向或固定 materials 数量。

商品目录、线上读取、经营数据写入的边界仍见 [listing-catalog](../../SKILL.md)。缺少店铺基座允许继续，必要事实缺失时补问；策略建议不能写成经营承诺，填写稿完成不授权线上发布。
