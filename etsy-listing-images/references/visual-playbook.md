# Etsy 商品图的视觉决策

这份文件用于策划、改稿和出图前选择画面。结论分为官方支持、卖家经验和本技能工作默认；经验不是平台规则，也没有未经验证的转化率保证。研究日期：2026-10-10。

## 从买家看到的商品开始

Etsy 的搜索图和商品图库不是广告落地页。首图应先让人辨认卖什么；附图让人看清实物、感受尺寸和用途、选择变体、理解定制。图内文案只补充照片无法直接说清的事实。

默认先画摄影构图，再决定是否需要标注。以“完整商品 / 使用状态 / 材质局部”决定画面，不从“大标题 + 图片框 + 金线 + 标语”模板开始。统一可以体现在曝光、白平衡和商品颜色，而不必统一成同一张海报。

### 主图

- 单一、明确的商品主体；通常无新增文字、无拼图、无促销按钮。组合出售可展示实际套装，不能让单件误看成整套。
- 棚拍或生活场景均可；以哪个更快说明商品为准。背景提供对比或使用语境，不抢注意力。
- 主体尽量清楚、足够大，同时保留裁切余量；不规定通用于首饰、家具、卷轴的面积百分比，更不把大量留白当作“高级感”的必要条件。
- 细长商品先保留真实形状，利用正面视角、明暗对比、合适取景提高识别度。展示完整外观后用附图补细节，不用拉宽、夸大或多个副本填满画面。
- 用真实定制成品吸引买家；定制方式放附图说明。先读平台文件判断首图素材资格。

### 附图

| 买家疑问 | 画面证据优先 | 文字仅用于 |
|---|---|---|
| 到手长什么样 | 不同有效视角、表里结构、实际包含物 | 必要的包含/不包含说明 |
| 质感和值不值 | 有来源的清晰局部、真实制作过程 | 材料名或关键工艺，省掉空泛品质口号 |
| 多大、放哪里 | 有依据的比例场景、尺寸箭头 | 数值、单位、测量边界 |
| 哪款适合我 | 同尺度真实变体对比 | 与选项一致的名称、规格 |
| 定制什么、怎么选 | 实际成品样例及可选内容 | 简短步骤、已确认范围，不能编造服务流程 |
| 是否适合送礼 | 成品在生活中的效果，或真实包装 | 有依据的送礼信息；缺包装不虚构礼盒 |

附图可充分使用横向画幅，按商品语境加入适度的桌面纹理、纸张或布料等环境层次，不把“干净”固定成白底与大面积留白。装饰不能遮挡细节、假装包含物或充当未证实的工艺证据。作品合集按题材跨度选样，在手机仍能辨认的前提下增加案例，过多时分图，不固定数量。

商品/材质/过程照片应占视觉主导；尺寸、变体、定制说明可以是清楚的信息图。不固定照片和信息图的张数比，但若大多数图离开大标题就无法表达价值，应重做策划。相同照片配不同标语不算新增信息。

工艺证据图采用真实照片裁切/排版，避免让生成模型重绘工匠的手、笔迹或操作后仍声称是原始制作记录。需精确保留而当前工具无法做到时，保留原件，或在已授权范围内改用可用的确定性排版工具；涉及新增服务、权限或显著成本再征询，不以生成图冒充原照。

### 新增标注与信息密度

以 SKILL.md“生图前执行约束”为规则源。首图默认无营销叠字；附图可按买家问题安排必要的短标题、尺寸、选项和包含物标注，不以一个标题块限制所有信息图。无字照片仍可使用，商品原生刻字保持原样，不计入新增文本。

在实际生图工具输入中逐字列出计划新增的文字，并禁止未计划口号、角标和页脚。主图为适用的方形、横向和纵向缩略图留裁切余量，附图默认按完整画幅指定内容边界；尺寸等信息图需要多处独立标注时，先核对事实并设计清楚的版式，在已授权图库范围内执行，不重复索取例外许可。

双样例并列易被误认套装时，调整构图或用清楚的包含物说明解决；图内仍说不清时在交接中标出风险，不放行误导图片。必读文字在手机预览中须清楚；主图检查适用缩略图，附图按完整画幅及已知展示位置检查，不得把不适用的方形限制施加给附图。

## 执行与整套复检

以下用于把已确认方案落实到成图，不是新的平台规定。策划时应用，交付前用同一组标准复查；局部修改只重查受影响图片与跨图关系。

### 制作前核对

复用现有策划表、事实表和提示词文件，不另建平行资料系统。生成前让本张输入中的下列信息可核对：

| 项目 | 实际需要确定的内容 |
|---|---|
| 素材映射 | 哪个文件是本款身份依据，哪个只供风格/人物/布局参考；原图编号与传给工具的顺序一致 |
| 变体边界 | 仅颜色不同、宽度/结构不同、仅内部不同，分别是什么；不得混用另一款的身份参考 |
| 尺度依据 | 测量的是主体、含连接件总长还是绳长；与佩戴参照有什么关系，哪些只能估计 |
| 构图差异 | 本张增加什么信息，哪些机位/动作/服装/背景改变，哪些整体风格保持 |
| 排字 | 已确定的英文、字形/字重、对齐与位置；不遮脸、不遮商品及适用裁切边界 |
| 排除项 | 已放弃的款式、包装图、被拒绝的参考、错误版本和其他本次明确排除内容 |

这些是工作记录，不要求用户逐字段确认；已有证据就直接填写。参照图数量有限时保留本款关键身份图，压缩风格参考，不因名额限制丢掉真实商品而只用生成图续画。

尺度核对要区分问题：已知主体尺寸先保持长宽比例，再用原始佩戴照比较其与人体的相对大小；组件也单独对照，不能只改吊坠却把珠子留得过大。绳长不等于佩戴垂落距离；不能根据未知绕法、人体比例反推精确长度。只知道相对大小时给相对判断，无法保证的佩戴落点不写成测量结果。

### 素材角色与处理方式

- 明确每张来源是商品身份参考、风格参考还是直接使用的最终照片。用户要求参考原图重新生图时，保持商品身份并重新安排获准的场景/构图，实际调用图像生成/编辑能力，不能以裁切、贴大纯色底或复用供应商排版替代；用户要原图细节或真实过程证据时也不反过来强行重绘。
- 授权范围明确后，检查来源店铺叠加水印、品牌宣传字、边框及截图界面是否进入新图。商品自身署名/刻字与外加水印分开处理；优先选无遮挡的原始角度，不让模型根据遮住的编织、纹样或连接处猜细节。授权不明时只核对必要使用范围，不重复问已确认授权。重构画面服务于当前展示需求，不承诺规避图片相似度检测或因此获得平台使用资格。
- 真实工艺资料须与本商品有可说明的关联；泛竹工照片不能仅凭同材质充当本款制作证据。用户提供可用微观照片/视频帧时优先使用实际可见细节；放大示意不能把毫米级结构画成粗木榫，更不能凭想象添加未见工序。示意与真实记录分别标注。

### 统一样式与有效差异

- 整套沿用已确认的画幅比例、光色和排字体系；本地用户已明确偏好统一横版时沿用，其他任务没有确定画幅时结合素材选取，并在计划中写明。不能因为参考照片横竖不同就让成品混用画幅，也不通过非等比拉伸人物/商品或加大色块边框凑比例。需要例外时说明具体展示理由。
- 统一风格不等于同一机位换人。不同佩戴图应增加有用信息，可改变服装、动作、取景或环境；用户更换人物/场景时检查整幅语境，不只换脸。不能因美国市场就推断所有人物必须某种族，明确的人物选择只作用于相应任务。
- 变体对照图采用可比较的角度、比例与光线，保留真实尺寸和结构差异；不可为了同尺度把本来不同宽度的男女款画成一样。只有内部不同的款式保持外观一致，用准确选项文字解释内在差别，绳子等自然姿态可不同；不造出可见内部或不同外壳。
- 每张附图回答不同的买家疑问。已确认的多用途要在策划中逐一考虑，缺场景证据或被用户排除时记录理由；不能用“最小集合”省掉关键使用场景，也不堆两张重复尺寸图或无助选购的放大局部。用户排除包装图时保持排除，不等于包装事实被否定。

### 比例、连接与文字的实际检查

- 佩戴/使用图以已知尺寸及原始比例为依据，同时核对主体、配件、绳长、纹样方向、编织收口和连接点。出现偏大时回到尺寸和参照，不能仅凭“缩小一点”反复猜。仅有手指参照时可用于相对比例判断，估算不得进入正式尺寸文案。
- 检查人物头身比例、手指和关节、衣服落点，以及绳/环/孔的实际穿接。钥匙圈不能穿过实体金属，挂绳不能漂浮或挡住正常使用；尺寸数字正确不抵消结构错误。碰水等场景表达不能自行升级成防水测试或性能保证。
- 排字沿用本任务已确认的字体与字重；无法精确识别生成图字体时说明是候选匹配，不把猜测名称当定论。中文卖点先按本技能语言规则转成英文；同级款式标签保持字体、字号与对齐基线一致，避免临时加粗描边、阴影去补救低对比。
- 文字优先放在不遮挡商品及人脸的清楚区域；图形已合格而只有排字失败时，优先采用宿主允许的文字编辑方式，避免重生整图让商品细节再次漂移。检查对比度和手机实际阅读效果。主图真正生成并查看适用裁切预览，核对商品身份、关键文字和用途提示；不能用提示词里写了安全区或只看完整图代替裁切验收。

### 可核对的验收记录

在现有图片清单中简记本次实际看过的最终文件、原图对照、主图裁切/手机预览及未通过项；可引用接触表与局部对比图，不另外强制建立新系统。先看整套接触表检查画幅、色调、字体和内容重复，再对有风险的图放大查结构与比例。用户指出漏检时重查该类问题在其他图片中是否也存在；不是要求全部重新生成。

确认后的局部修图列明改动范围，核对其他已确认文件未被意外替换。交付时给出最终图片目录、图片包与预览入口；图序变化同步名称、缩略图、ALT及资料包。视觉已确认的事项不继续显示为“待视觉确认”，仍未核实的平台适用项单独保留。

### 返工与防回退

收到反馈时先定位原因，再决定最小修改范围：

| 反馈类型 | 修正方法 | 复检重点 |
|---|---|---|
| 商品变形、比例偏大、纹样方向错误 | 回到该款原图及尺寸，修受影响部位或重生本图 | 主体与组件比例、交织方向和收口，不只看整体像不像 |
| 同一场景重复、衣着不合适 | 保留商品身份，调整整个必要场景关系 | 人物、服装、动作、背景和取景是否真的改变，而非只换脸 |
| 字体、字重、位置或裁切错误 | 沿用已确认图像，修文字或必要构图 | 精确英文、同级标签基线、手机对比度和实际裁切 |
| 用错素材/款式或实物范围变化 | 更换身份来源，撤下受影响图片及标签 | 不能让成品图库继续暗示出售已取消的材料包或另一石种 |
| 工艺示意与实物细节不符 | 优先采用可用原始细节，缩小主张或换展示方式 | 不以“示意”标签掩盖明显错误的粗细、结构或制作关系 |

“统一角度”用于便于比较的选款图；“换人物、换场景”用于增加生活用途信息，两者不能互相套用。用户对本次具体图的例外优先，不把同背景的明确请求机械判为重复。

修图前记下当前已确认版本及本轮改动范围，修后与它及原始商品图分别比较。未请求修改的成图直接复用；需要证明未变时对比文件哈希，不能仅因文件名相同就说没变。使用构建脚本更新HTML或压缩包前确认脚本读的是当前清单，避免旧脚本把已修正的图、文案或状态覆盖回去。

每次失败记录具体差异与下一次策略变化；不是重复同一提示词或只加“更真实”“严格保持”。同一问题连续两次修正未通过时遵循主文件停止规则，保留最好版本及具体缺口，不让错误版本累积进最终包。修正后重新检查受影响的结构、文字、裁切和交付引用，不能只检查用户刚指出的一小块而忽视新引入的问题。

## 经验来源与分歧

### eRank：跨比例裁切

[eRank 图片指南](https://help.erank.com/wp-content/uploads/2025/11/photo-guidelines-for-etsy-listings.pdf)，指南注明依据2025-11-11的官方材料，本次已读。

建议居中与适度背景空间，并演示方形、横向、竖向裁切；倾向以横向源图作为较稳的起点。它也指出为了兼容裁切而留白过多会让主体显小。采纳实际裁切检查，不采纳“某一个比例在所有类目必胜”，不把其关于图像被拉伸的措辞写成应主动拉伸商品。

### 卖家/买家社区：氛围与识别度存在真实分歧

[首图吸睛还是直接展示商品的讨论](https://www.reddit.com/r/EtsySellers/comments/18hpiz1/using_an_image_to_catch_someones_eye_vs_straight/)，2023-12，低强度经验材料。

有人更喜欢有场景的照片，有人认为道具让人分不清卖的是手链还是散装配件；也有人提醒在手机/搜索缩略图中检查。采用其可观察问题：卖什么是否清楚、道具是否误导、缩小后是否可辨。意见票数不能证明哪种风格带来更多销量。

### 分歧处理表

| 分歧 | 当前决策 | 何时让用户判断 |
|---|---|---|
| 白底 vs 生活场景 | 两者都可；匹配品类、已有真实素材和搜索识别度 | 两个方案均合格但表达不同品牌气质时，给具体对照 |
| 方形 vs 横向 | 以裁切结果选，不把偏好叫硬规定 | 两者出现不可兼得的展示取舍时，说明会损失什么 |
| 首图大字卖点 vs 无字摄影 | 默认采用 Etsy 官方的无营销叠字建议 | 用户明确要求例外时解释建议性质，保留真实商品要求 |
| 用满图库 vs 精简 | 只保留提供新证据的图片 | 增图需要真实新素材或显著成本时讨论范围 |
| 强一致性 vs 多种照片类型 | 锁商品身份、色彩与必要的标注样式；允许镜头/场景变化 | 已有品牌规范与清晰商品展示产生实际冲突时 |

来源冲突先核对时间、类目和证据等级；政策优先于经验。不确定的审美/商业取舍可给用户2个具体方案并建议一个，不要求用户裁决平台事实，不把问题无限上抛。

## 本次卷轴案例的反例检查

这些是2026-10-09试做中观察到的失败，用于改稿判断，不能推广成所有品类的固定版式：

- 大衬线标题、金色分隔线、左右分栏和长脚注占据多张图；看起来像宣传册，缺少大幅商品摄影。修改目标是提高实物可见性，不是把标题换个字体。
- 原始粉色书法样例反复用于定制与送礼两张，未增加蓝色实际成品信息；样例可辅助解释，但不能替代出售商品的证据。
- 两张已经生成的“尺寸图/纸质细节图”文件实测都是1254×1254，虽然提示词要求2048。这证明提示词里的目标尺寸不等于文件规格；检查实际文件，放大也不会自动恢复细节。
- 原稿笔形与花纹被重绘后仍不一致；画芯20×70与卷轴34×150还曾出现比例偏差。要分别验收，不能靠正确的数字标签盖过图像错误。
