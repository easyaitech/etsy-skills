# Etsy listing 图片

交付适合 Etsy 搜索与商品图库的图片：先让人看清买到什么，再用真实画面解决尺寸、材质、用途、款式和定制疑问。默认摄影主导，图内文字只补必要信息。不要把“电商图”自动理解为大标题、宣传标语与小商品照片的海报。

中文沟通，新增说明用英文；商品自身文字、书法、印章保持原样。支持各品类，但先辨认实物、数字商品、定制商品及生产伙伴等情形，按对应规则选择呈现方式。只制作图片与策划，上传/发布另按用户授权处理。

完成条件：获准范围内每张图通过平台适配、商品保真、视觉表达和文件规格检查。未通过的只标为草稿，不混进可发布成品；生成数量达到计划不等于任务合格。

## 开始前

- 已有 `product-definition.md` 时，先读对应 Listing 的已确认定位、市场、购买理由、视觉证据要求与事实边界，在图片计划记录路径与版本。产品定义负责“表达和证明什么”；本技能依据买家问题和真实素材决定图片数量、顺序、构图、英文标注与具体设计，不把上游的建议张数当作硬性配额。沿用定位决定，把核心价值转为真实画面；提议中的包装、用途或变体不当作已有实物。新证据与核心定位冲突时提出修订并确认受影响决定，普通构图调整无需重做定位。产品定义确认不代替本技能的策划和主图确认。
- 用户要求先明确定位，或本次任务需要重新选择主攻人群与购买理由时，使用 [Etsy 产品定义](../etsy-product-definition/SKILL.md)；单独修图或执行明确方案直接继续。
- 策划前读 [Etsy 要求与来源](references/etsy-requirements.md)，按其中链接核实相关当前官方规则。区分政策、官方建议、经验与本技能默认。
- 策划、改稿或选择构图时读 [视觉方法与取舍](references/visual-playbook.md)。它包含 Etsy 摄影方式、卖家经验分歧及通用电商 skill 的取舍，不必加载其他平台技能。
- 优先沿用用户已说明的商品事实、偏好和确认。只有会改变商品真实性、关键视觉方向或执行条件的信息才补问。

## 1. 素材与事实

先确认主要目标市场（国家或地区）；用户尚未说明时主动询问，不能从对话语言、商品文化或 Etsy 平台推断。面向多个市场时确认主市场，或是否需要分别制作场景版本。已有明确答案则沿用，不重复问。答案未明确前可整理商品事实和不依赖市场的图序，但不定稿或生成依赖地域的生活场景。

将目标市场落实为具体场景设定：住宅空间与布局、家具尺度和样式、日常道具及使用习惯。结合目标买家与参考照片，不把一个国家等同于单一装修风格；例如中文书法也可以出现在美国买家的日常家居中，不默认配中式客厅。仅当人群或居住类型会实质改变画面时再补问；不熟悉的地域场景先查当地真实参考。市场本地化改变环境，不改变商品身份；图上英文的既有约定保持不变，除非用户要求调整。

查看全部图片，整理简短事实表：商品/变体、尺寸及测量边界、材质、不可改变的细节、实际包含物、最多三个主要购买理由及依据。每个素材注明角色：真实成品、真实过程、供应商参考、书法/图案原稿、示意图。不能把后四者自动当作当前商品成品照。

图中文字与用户描述冲突时指出矛盾；照片看不出材料成分或精确尺寸就列未知。缺信息仍可推进不依赖它的策划。供应商图片的使用资格依平台规则判断，不因“用户提供”就认定可直接作为 Etsy 首图。

商品身份锁定：轮廓、比例、组件、颜色、材质与表面处理、纹样、印章和所有商品文字。可改变场景、道具、光线、构图，以及有真实素材支持的角度。未拍到的背面、结构和新款不补造；光线调整不能让纸变布、哑光变亮面，也不能新增磨损来营造真实感。

## 2. Etsy 图库策划，等用户确认

先策划，不调用生图。优先规划清楚的商品照片，再按需要增加信息图；不固定7张、10张或用满平台容量。选每张图都能增加信息的最小充分集合，并解释数量理由。

策划表列：顺序、买家问题、画面证据/照片类型、主体与构图、对应素材/变体、英文标注（可无）、必须核对点及缺失素材。明确目标市场及相应场景设定、首图资格、建议画布尺寸与比例、整套色彩/光线方向。只锁保持一致所需的要素，不把所有图锁成同一左右分栏模板。

陌生品类或视觉方向不清时，查看少量同类 Etsy listing 的实际图片或用户给的参考，记录商品如何占据视线、场景用途、附图分工与裁切表现；仅有搜索摘要不能当作已看过图片。借鉴展示方法，不复制他人的作品或品牌；排名、销量标签与个人偏好都不能证明某种图片造成高转化。已有清楚方向时无需每轮重做竞品研究。

- **首图**：默认单张清楚的商品摄影，无新增营销文字、拼图、促销按钮。缩小后先看到商品而非标题或道具；实际套装与单件数量不混淆。定制商品先核实真实完成样例，缺失时列为待补首图素材，可继续附图策划，不把合成的不存在成品标成合格首图。
- **后续图**：依据买家疑问选择真实使用场景、尺度、材质细节、变体、包含物、定制说明、过程或包装。顺序按当前商品决策需要调整，不套广告的痛点—利益—优惠—CTA。
- **信息图**：用于尺寸、选项、下单说明等照片无法独立表达的内容。文字短而具体，商品依然清晰；同一照片配不同口号不算两张有价值的图。
- **礼赠/手作**：用真实成品、已知包装或实际制作过程表现，不能只放情感标语，或生成假工匠/假包装作证据。

官方要求与经验冲突先遵从官方；场景、比例或品牌方向均合理而难取舍时，给用户具体方案及利弊再问。不要为普通实现选择反复确认，也不要要求用户判定平台事实。

展示策划并等用户确认。已有确认继续有效；用户明确调整范围或流程时遵循其最新指示。

## 3. 主图制作与后续确认

先制作获准主图，完成核对后交用户确认。确认后询问“一次完成剩余图片 / 逐张制作确认”，除非用户已经指定。选批量后不逐张再问；用户要求先做其他图时可以继续，保留主图未通过状态。

执行生成/编辑使用当前 Hermes profile 的 `image_generate` 工具及实际可用看图能力，先按项目接入协议核验 schema 和参考图能力，供应商原图、真实产品照片与原稿直接作为输入，明确角色。工具要求优先于参考仓库中的第三方API或脚本，不自动换服务商。

给每张图的简洁执行规格：

1. Etsy 位置与买家问题：首图还是哪种附图。
2. 商品及来源：使用哪张原图、哪个变体，保真重点。
3. 主体画面：目标市场与具体住宅/使用环境、真实动作、镜头、自然光及裁切空间；摄影是主角。
4. 文字：默认无；逐图列出准确的叠字白名单（无字则为空），提示词明确禁止白名单之外的副标题、正文、脚注、角标、装饰性字母和自动生成的说明。所有带字图片按视觉参考中的手机端规则使用大字短标签；商品原有文字单独锁定，不翻译、不简化。用户要求不加小字时，将此约束逐张传入，不能因主图获准带字就给附图自动加标题层级。
5. 统一要素和允许变化：商品身份、色彩准确、需要时的标注样式。
6. 实际物理尺寸、目标画布规格、该图特有误导风险。

不依赖提示词中“preserve exactly”保证笔画或纹样准确。每次返回原始素材核对，已生成主图只是视觉参考，不能取代原件以免误差累积。图像模型不能凭空提升低清素材的证据价值；无法看清的细节不得以虚构微距补足。

纯裁切、原照排版和实拍证明图尽量保持原始像素；若当前工具不能可靠保留，说明限制并按环境约束选择或请求用户授权合适工具。不得把生成模型重绘后的手写过程称作未经改动的现场照片。

### 低清照片增强（按需）

用户要求提高清晰度，或获准制作范围内的照片模糊、压缩失真影响商品辨认时，先检查原始像素和模糊位置，再做保守增强；清楚的照片不重复处理。增强与更换场景分开执行，默认保持原构图、比例、颜色、动作和内容，使用上述 Hermes 执行路径。

- 以原照直接输入，优先减轻压缩伪影、改善边缘与局部对比。原图无法辨认的细节保持不确定，不凭空补全字、笔画、印章、纹样、材料纹理或身体部位；不以过度锐化、假颗粒、塑料皮肤制造清晰感。
- 增强后与原件在相同显示尺寸下并排比较整体，再放大对照关键区域。商品图核对文字、纹样、边缘、材质与结构；制作过程图额外核对手指数量与姿态、工具握持、笔尖/工具接触点、已有及未完成笔迹。再检查手机端是否确实更易辨认，而非仅输出像素变多。
- 只有清晰度改善且可核对的关键内容没有改变，才通过增强验收；不能证实的细节明确列为未核实。出现笔画、动作或商品身份变化时按第 5 节的修正与停止规则处理，保留原照或说明需要更清晰原件，不把“更清晰”当作“更真实”。
- 始终保留原图，增强版另存为带 `enhanced` 的版本，并记录来源及实际文件规格。生成式增强在交付说明和预览页中标为“AI 清晰增强”；如有模型重建细节则说明范围，不能称为准确恢复或未经修改的实拍证明，也不能提升它的 Etsy 素材资格。仅凭增强后的高像素不能宣称获得原生高清细节。
- 替换获准图库中的版本时同步更新图片链接、名称、规格记录与新压缩包，保留原图可追溯；其他已确认图片保持不变。

## 4. 照片真实化

每张照片完成构图后、最终排字与验收前，执行真实化检查；发现问题再局部编辑，已自然的照片保留，不为走流程重复生成。该步骤借鉴来源技能的 R1/R2 和两阶段方法（要点已完整保留在下文，不依赖其他技能），执行要点如下，无需依赖它才能完成本流程。

- 主图默认 R1：清楚、干净的商业实拍感；生活场景默认 R2：目标市场普通住宅、自然窗光、克制道具。R3 手机随拍感仅在用户要求时使用，不用噪点、模糊或低清冒充真实。
- 先修物理问题：光向与明暗衰减、墙面/桌面的接触阴影、悬挂或支撑关系、合理反射、真实比例与适度景深。材质表现依原件，不能凭材料名添加原图不可见的纤维或纹理。
- 再看布景：减少样板间感、过度对称、公式化道具、电影光、过强虚化与 HDR；保留已确认场景方向及当地生活逻辑。只有确有问题才改，不每张都加同样的“生活痕迹”。
- 商品保真优先于真实感：不新增商品褶皱、卷边、污渍、磨损或改变书法/纹样。优先调整环境与光影，每次仍对照原始商品素材，不以生成版本作身份真值。真实制作过程照片保留原件，不重绘为“更真实”的制作证据。
- 信息图只处理其中的照片区域，保持标注、尺寸箭头与版式准确；避免让真实化重绘已确认的英文文字。处理后重新检查商品身份、文字和裁切。合成图更像实拍并不使它变成真实成品照片，素材资格仍按 Etsy 规则判断。

完成条件：物理关系可信、布景自然、原件细节未改变；无法同时满足时保留较可靠版本并标注具体限制，不以美观抵消保真失败。

## 5. 四项独立验收

### A. Etsy 适配

按平台参考检查素材资格、定制成品首图、格式与裁切；不把建议误写成禁令。首图默认无营销叠字，附图的示意/实际包含物不会误导。看到 mockup 先检查是否适用于当前类目及图片位置。

### B. 商品保真

逐图对照原件放大查看文字、笔画、印章、纹样、材质、结构、组件、颜色与各变体一致性。只能辨认字义而笔形改变不算通过。

整套一致性另行核对：同一件商品跨首图、细节图、掌心图与佩戴图时，逐一比较外轮廓、长宽比例、孔位、色块、纹样及刻字位置；只保持颜色或材质不算一致。已确认的视觉版本用于跨图对照，原始素材仍用于事实核对，二者不混淆。

实际比例单独检查：长宽高、画芯与外框等内部相对尺寸、人与家具参照及透视。尺寸数值来自事实表，单位换算与箭头位置正确；数字正确不能抵消画面比例错误。普通手/道具只作尺度辅助，不是精密测量证据。

### C. 买家看图能否理解

- 生活场景是否符合已确认市场和目标买家的实际环境？检查家具、空间、道具与使用方式，不能只在提示词里写国家名而画面照旧，也不能用刻板文化符号替代真实生活。
- 先逐项核对叠字白名单：额外文字、重复解释、页脚或读不清的小字都判为未通过，不能靠“整体好看”放行。删减优先于放大；必要数值、单位与避免误导的标签保留为清楚大字。草稿/审核状态记录在预览页及交接清单，若图片独立使用仍会误导，则保留醒目的短标识或停留在草稿，不用小脚注补救。
- 所有图片均检查手机端表现：首图在250px与300px居中正方形预览中，商品及必要叠字完整可辨；所有带字附图在约360px宽的完整图片预览中，必读文字无需放大可读（本技能内部检查，不是平台尺寸标准）。先删冗余文字、调整换行与布局，再增大字号；不能把商品挤成配角。实际查看预览后才能报告通过。
- 检查方形、横向、竖向裁切的关键主体；有平台预览则以它为准。没有实际看过模拟/真实预览就不能报告“裁切通过”。
- 摄影图暂忽略叠加文字，是否仍然展示商品价值？若必须靠大段文案解释，改用更有效的商品照片。尺寸、定制等信息图按其功能判断，不强求无字。
- 整套是否展示了不同证据，而非同一张照片换标题？是否大量海报、装饰线和留白挤掉了商品？身份与光色一致，不等于每页版式重复。

### D. 实际文件

用可用的文件检查工具读取像素、格式、透明度、色彩信息及文件大小，不把提示词目标当作结果。对照已核验的 Etsy 建议说明是否达到目标。未检查的字段报告未核实。

**最终导出尺寸门槛**：按用户确认的交付标准，每张最终图片必须满足 `min(width, height) > 2000`；默认短边 **2400px**，已有更高分辨率无需缩小。4:3 图片可导出 3200×2400，其他比例按原比例计算长边，不拉伸或裁切来凑尺寸。这是本技能的交付标准，Etsy 官方的“宽、高至少 2000px”仍按建议表述，不改称绝对上传门槛。

原文件不足时，优先采用用户已授权的普通等比例缩放，保留原件和现有构图、文字、书法及商品内容；生成式增强需另按其授权与保真检查执行。插值放大只满足像素尺寸，不称为原生高清或恢复真实细节。尺寸未达标的文件不能进入最终交付包。

用户确认视觉设计后，在首次完整图库交付及交接上架技能前完成最终导出，不把工具返回的低分辨率草稿当作完成版等待用户催补。

在全部处理（含 AI 标记清理）完成后，重新打开最终文件逐张测量，记录实际宽高与缩放方式。打包后读取压缩包内的实际图片，再核对数量、宽高和文件完整性；不能用源图、预览图或打包前记录代替最终文件验收。

任何一项失败都不能被其他项抵消。针对明确问题修正；同一问题连续两次修正仍失败，停止该图，交代具体原因和可行替代素材/方式。用户已授权的独立其他图片继续推进，不无限重试或暗中降低标准。

## 6. 最后清理与复检

所有生成或生成式增强图片在最终交付前，用 `remove-ai-watermarks` 处理独立副本；用户只要文件、不发布时同样执行。按 [AI 标记清理](references/ai-image-cleanup.md) 操作并记录结果，原图保留。处理后再次检查文件与画面；入库、预览和打包使用同一处理版。此步骤不能提升图片已有的商品保真、首图资格或分辨率验收状态，也不能把清除元数据说成消除全部 AI 痕迹。

## 7. 交付

每张图独立文件，按图库顺序命名，修改版保留版本区别且不覆盖原素材。给预览与实际文件路径/链接；多图可另给压缩包。简短区分“通过并待用户确认 / 概念草稿 / 未通过”，说明素材或文件限制。

已知错误的图不进入“可上传成品”包；若用户需要看草稿，单独标识。变体顺序、英文名称和尺寸保持与计划一致。交接时按最终图序列出每张图片的文件路径、版本、实际规格、素材角色（实拍/合成/增强等）、验收与用户确认状态、对应变体及关键图中文字；沿用图片计划或另附清单均可。仅将验收通过并完成适用确认的最终图库交给上架技能；计划、预览和失败草稿保留独立身份。

在产品定义→图片→上架的完整流程中，最终图库就绪后自动继续 [Etsy 信息生成](../etsy-listing-builder/SKILL.md)，让其实际查看图片后编写逐图 ALT 与最终 HTML 填写稿。本技能可提供画面事实说明，不代替最终 ALT；独立图片任务不自动扩大为上架任务。后续改图要标明受影响的序号/文件，提醒同步 ALT 和填写稿。
