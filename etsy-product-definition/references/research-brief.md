# 可选调研的首份交付：可转交的调研需求

仅在用户选择调研时读取。下文是完整研究的参考范围；任务书按用户选择裁剪，只查关键词时保留大类发现、机会筛选、关键词数据和必要的搜索结果意图核对，省略定价、买家反馈和完整竞品研究。用户已定价格和图片方向直接沿用，除非用户要求检验。跳过调研时不生成此报告。

输出 `research-brief.html`，同步保留同内容 `research-brief.md`；按 [HTML 报告交付](html-report.md) 制作。用户委托其他研究者时，任务书应可独立转交；用户已授权本代理研究时，界定范围后直接执行，不等待转发。将具体商品事实带进去，不把旧定位草稿当成预设答案。

## 任务书的必要内容

- **任务与决策问题**：研究后究竟要选择什么；本轮只做约定范围的研究，不代替最终产品定义、Listing 或图片制作。
- **已知事实与未知项**：实物、工艺、可做定制、市场、包含物及已确定的价格/成本口径。明确哪些是店主声明、哪些未证实；已定价格作为经营选择记录，仅在用户要求时检验。
- **定价决策**：仅在用户选择定价调研时，研究可比配置的价格、供给与购买线索；回传依据供产品定义阶段提出建议，不为用户已定售价寻找背书。
- **候选需求**：完整定位研究时从商品能力提出可检验方向，允许发现新方向或保留现有方向；专项研究只围绕约定问题，不强制比较所有人群或用途。
- **检索与采样**：选择关键词研究时执行下文“大类发现与机会筛选”；其他专项只采集回答约定问题所需的资料。按问题给适度的建议工作量及优先顺序，数量可调整，不把它写成研究质量门槛。
- **回传字段**：按约定范围提供关键词数据、竞品配置/价格/表现或评价证据，以及来源索引；保留证据编号便于下游引用。格式可为 CSV、表格或结构化 Markdown，保持字段含义即可，不强求额外转换。
- **分析与反证**：对本轮要判断的方向或问题说明支持、反对、证据强度与能力缺口。允许结论是证据不足；找不到精确竞品不能证明蓝海。
- **完成与受限报告**：返回原始资料和有证据引用的摘要、访问/套餐限制、遗漏原因与补充建议。不要只交评分、截图堆或 AI 摘要。

## 大类发现与机会筛选

仅在选择关键词研究时执行本节。

目标不只验证现有设想，还要发现商品可以进入的更大搜索需求。沿两条路径研究并相互校验：从实物向上寻找所属品类；从大类高搜索词向下寻找可承接意图。材料精准词搜索少，不足以否定整个产品机会。

1. **建立类目层次。** 从材料/具体款式回到商品类型和上位品类，再展开功能、定制内容、人群/关系、场合和风格。比如琥珀吊坠 → 吊坠/项链 → 首饰；在项链下发现名字、宠物、日期等需求。这里是研究路径，不是预先认定这些词排名高。上溯到仍能提供相关需求线索的层次即可，不无限扩展到所有礼物。
2. **先看大类，再扩词。** 利用账户当前可用的类目报告、关键词相关词列表或其他可追溯的品类词数据，按目标市场的可比较搜索指标排序。除给定种子词外，主动记录新出现的高搜索需求；只手查几条自己想到的词不构成大类探索。额度先覆盖不同上位品类/需求簇，再深入具体材料词。
3. **单独交高搜索词榜。** 排名按同一国家、平台、统计窗口与明确指标排序；保留高搜索但不适用的词并写理由，让人能看到市场全貌。注明候选池怎么取得、数量、工具截断和覆盖范围；只能叫“本次候选池 Top”，除非确有完整类目榜，不能假称全 Etsy Top。平均与近期高峰榜可分开，缺值不强行排名，近义词不加总。
4. **再查本品如何承接。** 对相关的大词/需求簇查看实际搜索结果或工具样本中的商品形态、定制内容、价位、核心承诺和买家线索。例如 name necklace 可能主要呈现金属字母造型，刻名字的琥珀牌与其是否匹配仍需查看；pet necklace 也可能指宠物佩戴物而不是给主人佩戴。材质不同不自动排除，需求相同可以是有效替代；已有功能不同则不能仅凭字面相近套词。
5. **形成机会表。** 每个词标为“现商品可承接 / 经确认调整可承接 / 待查意图 / 不适用”，给出对应商品事实、搜索结果证据、竞争与季节性、能力缺口、可能的细分入口和下一步。可承接只表示相关性，不等于已证明排名或转化。需要调整实物或服务的单列，不暗中变成现售承诺。

高搜索量与高竞争可以同时存在，不按竞争高一刀切淘汰；比较需求量级、意图匹配、可见竞争形态和可兑现差异，说明取舍。不要把搜索/竞争简单相除当作成功概率，也不编造流量份额。用主词标明需求入口，用更具体的词帮助解释本品；最终标题标签由下游依据获选定位处理，研究榜不直接整份塞入 Listing。

选择关键词调研时，两张表属于回传要求。关键词发现可提出定位候选，但仅靠关键词不能宣称定位已经市场验证；用户可以结合商品事实和经营判断确认定位，无需补齐完整研究。

## eRank 与实际页面的分工

以下只在本轮研究涉及相应工具与数据时使用。以账户当前可用功能为准，不固定付费套餐、配额或界面路径。选择 Etsy 与目标买家国家，记录字段自己的地域口径；某些竞争指标未必是该国专属，不能统一改写为美国数据。按相关性先筛查询词，再用可用额度深入比较。

关键词表记录原词、所属需求、平台/国家、查询日、统计时期、平均搜索/点击/CTR、竞争、趋势、相关词及来源；不可用值保留原状，不补零。CTR不是购买转化率，不能按搜索量×CTR估算销量。关键词之间需求可能重叠。

需要竞品证据时，可借助当前可用工具发现候选，再打开 Etsy 页面核对配置与表达，记录与研究问题相关的商品 ID、店铺、链接、采样入口和商品事实。仅在已选择定价调研时，按 [竞品定价与试售建议](pricing.md) 采样并回传可比配置价格表、不可比原因及价格带支持/反证；不用研究者直接替店主确定最终价格。记录所用指标的对象、单位、时间窗、估算属性和来源；不知道定义就标未知，不跨口径排名。

实际看图才记录首图/附图展示方式。评价需区分该商品与店铺总体，记录日期、主题、来源与简短摘意；AI 总结只是线索，需回查。不得据店铺所在地推断评价者国籍，未标明买家市场就保留未知。

## 回传模板的字段组

按约定研究范围选用以下字段组；范围外字段不要求补齐。

- `category-top-keywords`：T 编号、类目层次/需求簇、关键词 K 编号、排名及排序指标、候选池范围/来源/截断、国家与时间窗、搜索/点击/竞争/趋势原值、与本品初步相关性；不适用的大词也保留理由。
- `keyword-opportunities`：O 编号、K/T 编号、搜索意图及实际搜索结果的来源编号（有竞品记录时可用 C 编号）、本品承接状态、事实依据、差异、能力缺口、细分入口、验证动作；与高搜索词榜分开，避免只展示筛选后的赢家。
- `keywords`：K 编号、keyword、上位类目/需求组、发现路径（种子/类目/相关词）、platform、country、查询日、统计区间、各指标原名/值/口径、趋势、source_id、限制。
- `competitors`：C 编号、listing_id、shop、URL、直接/邻近/替代、检索入口、商品及配置、定制、价格/币种/运费/优惠、制作时间、图片实际观察、承诺与服务、表现指标及口径、source_id。
- `pricing-comparison`：P 编号、C/S 编号、直接/邻近/替代、采集日、目标国家、选中配置、原币现价/促销条件、必要定制费、运费、税费口径、可比较总额、差异与不可比原因、购买证据及局限；可作为竞品表视图，无需重复录入。
- `buyer-evidence`：R 编号、C 编号、商品/店铺归属、评价日、买家市场已知/未知、购买场景、简短摘意、主题、反例、source_id。
- `sources`：S 编号、URL 或回传原始文件名、访问日、工具、筛选条件/配置、局限。

字段多时可以拆表，不在单个单元格里混合多个不可追溯指标；证据编号必须互相对应。
