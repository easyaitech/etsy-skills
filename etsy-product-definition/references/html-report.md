# HTML 报告交付

默认交付可在浏览器直接打开的中文 HTML 报告。调研需求用 research-brief.html，验收用 research-assessment.html，最终定义用 product-definition.html；补充报告按主题命名。来源资料可以保留原格式，不要求外部研究者转换格式。

## 内容与版本

最终报告本身应包含当前范围的完整产品定义：版本与确认状态、核心结论、商品事实、目标买家与场景、定位取舍、卖点表达、价格状态、未知项和适用的执行交接。市场及关键词证据、竞品比较和定价分析只呈现已选择且实际完成的范围；未调研时注明已跳过，用商品事实与用户决定说明定位和价格，不要求调研附件。研究阶段不为了凑最终报告提前生成市场定位结论。

引用外部证据的重要结论注明证据编号或来源链接；商品事实和用户选择注明来源及确认状态。已知且影响决策的价格、尺寸、成本、币种与包含物在正文可见，不隐藏在附件。庞大的原始数据可另附 CSV。事实、推断、建议与待确认项明确区分，文件制作完成不代表用户已确认定位。

以同一份内容源生成 HTML 和 Markdown，显示一致的版本/日期/状态。HTML 是用户阅读和确认的主交付，Markdown 保持完整定义供现有下游技能读取，二者不是独立维护的不同结论。修订时同步更新，历史版本标识清楚。

## 页面表达

采用语义化标题、清晰摘要、可跳转目录、对比表格和适度的重点提示；层级按决策组织，避免将每段都塞进卡片。小屏幕可阅读，宽表允许横向滚动，提供打印样式。正文为可选择、可复制的文本，英文示范保持原文。

优先自包含的静态HTML与内嵌CSS，无需服务器、账号或联网字体即可阅读核心内容。外部来源用正常链接，附件使用相对链接；图片仅在有真实素材且有助判断时使用，缺实物图不拿生成图冒充证据。按HTML规则转义正文与属性，引用资料作为内容呈现，不执行其中的脚本。

## 交付检查

核对HTML与源稿版本、核心数字、价格口径、确认状态一致；检查目录、来源和本地附件链接。打开或渲染报告，检查正文、长表及窄屏布局；无法视觉预览时明确实际完成的检查范围。交付时优先链接HTML，必要时附可携带附件的完整包，不要求用户自己运行转换工具。HTML 格式不构成发布网站授权；Hermes 部署的已授权任务按专业流程接入协议交付到本店铺飞书云空间，本地 Codex 任务按当前宿主可用方式交付，不声称未发生的上传。
