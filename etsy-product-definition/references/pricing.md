# 竞品定价与试售建议

仅在用户需要定价分析时使用。用户已定价且未要求分析时直接记录，不执行本参考；用户要价格建议但未选择定价调研时，不新增竞品采样或要求竞品对照，按已有资料给条件化建议，资料不足则保留待用户决定。以下采集、竞品对照与研究输出要求仅适用于已选择定价调研的任务。

目标是从已选定的定价研究得出可执行的价格判断，同时区分市场标价、已发生交易的证据、卖家成本和策略建议。用户需要价格建议且资料足够时，产品定义给出推荐价或试售区间、理由、适用配置与未知成本；资料不足时给条件化建议或保留待定，不编造精确区间。用户已定售价且未要求检验时只记录，不改写成新的推荐价。

## 调研时采集什么

按购买需求与交付配置分组：同类同定制深度为直接参照；不同材料或工艺但满足同一需求的商品可作邻近/替代参照。逐条保留商品 ID、独立店铺、采集日期、目标市场页面、币种、真实选中规格，以及影响可比性的材质、尺寸或重量、配件、定制内容、包装、服务与制作配送时间。

价格分列当前选项成交前标价、促销价/条件、划线价、必选定制费、运费及已知税费。比较目标市场的“商品＋必要定制＋运费”税前支付额；税费另列。包邮是卖家承担运费，不是运费成本为零。只有起步价、搜索卡、非目标国家运费或缺配置时，保留为弱参考，不与完整套装混算。货币转换须记录日期与汇率来源，并保留原币；换汇不补足缺失运费。

收集相关单品评价、订单或工具估算的身份和时期；有评价不能证明买家按当前价购买，店铺累计销量不能证明该单品价位有效。同一店铺多规格不是多家独立样本。

回传价格对照表，指出相近价位有哪些配置、支持和反证。不强凑样本；直接可比样本充分时才报中位数/分位数并注明样本量，少量异质样本逐项比较。热门词搜索量不能换算买家支付意愿；不能仅按重量或尺寸机械推算定制商品价格。

## 从证据给出建议

明确基础配置（已能交付的商品、选项与服务），解释建议价落在邻近供给价格的何处：哪些价值买家可看到，哪些溢价理由还没有证据。相同手工、包装或定制是共同特征时不冒称独有。缺乏相近成交证据时，可给条件化试售价并说明依据与局限，不假称“市场合理价”。

区分三个数：竞品参考区间、考虑成本后的经营底线、建议试售价。底线取决于店主要求的单笔贡献或利润目标，未知时给情景而非伪精确底价。升级价仅对应确认能交付的增量内容/工时，不为了凑价格档位创造变体；自然尺寸差异不自动收费，需先明确分档和选货履约。

## 成本与压力情景

记录适用的材料、制作人工及步骤、沟通/预览工时、配件、包装、物流、预计返工/丢件、平台交易和收款费、广告、汇兑及其他费用。用户报成本范围时核对对应配置；范围未明确则给上下限，优先用高端检验风险，避免重复计算已包含人工。

费用按当前官方规则和收款账户地区核实；买家国家、发货国家不等于收款费率国家。广告区分按点击支出与归因订单费，分别设适用情景，不当作每单必然发生。未知费用保留变量或标注假设。

单笔贡献＝实际收取的商品/定制/运费收入－该单生产履约成本－适用平台/收款费－分摊获客及返工成本；税收代收部分不当营业收入。尚未扣全费用的余额明确叫“部分费用后余额”，不称净利润。

需要价格建议时，用有依据的情景显示建议价、成本上升、获客费或实际折扣的影响。给最低成交价建议前，明确利润目标与成本口径；推广折扣按折后实收复算，不虚构划线原价。

## 输出与迭代

在最终产品定义 HTML 中呈现本轮能支持的定价判断、核心竞品对照与费用情景；详表较多时另交 pricing-recommendation.html 并保存同内容 Markdown 源稿，主报告仍保留足以理解价格判断的内容。写清已定或建议价格及币种、包含内容、运费与税口径、实际可用的竞品参照、成本余额及遗漏项；有依据时说明调价条件。证据不足或价格待定时明确缺口，不为填齐字段编造数值。

观察实际搜索曝光、点击、咨询、定制工时、成交与退款。无曝光不能判定价格过高；变更价格时尽量保持配置及展示稳定，记录时间与流量来源，小样本只作方向信号。产品尺寸、配置或工艺更新时同步重评价格和展示，不沿用旧规格的溢价解释。
