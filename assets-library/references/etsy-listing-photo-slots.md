# Etsy 素材用途标签

## 3. 槽位 ID 与 Assets 素材池 表 用途标签 字段对齐

保留既有目录用途标签以兼容存量素材：`hero / variation / scale / size-chart / detail / lifestyle / packaging / brand-story / context / comparison`。旧标签 `Etsy listing 主图` 对应 hero，`Etsy listing 详情` 对应 detail。未分类素材可以暂留空，不能据此编造已覆盖画面。

这些是检索标签，不是平台规定的图序、数量或必拍项。图片计划由 [etsy-listing-images](../../etsy-listing-images/SKILL.md) 按买家问题和真实素材确定，不固定张数，也不强制三张细节图或礼赠场景。
