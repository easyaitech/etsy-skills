# 关键词与出稿规则

## 规则来源与优先级

真实商品事实和适用的平台硬限制不能被文案偏好覆盖；当前用户选择优先于旧写作默认。官方建议是建议，不升级为硬性禁令；用户偏好也不冒充官方推荐或搜索效果保证。平台资料、当前后台与旧记录不一致时，核对适用版本并说明差异，不机械取最宽或最严值。

### 本地已确认的写作偏好

以下来自当前本地用户，后续可明确覆盖。仅在当前店主已确认相同偏好时应用；多租户部署不得把它们视为另一店主已确认的设置：

- 标题以清晰品类开头，尽量充分利用140字符；可加入相关产品名词、用途、同义表达和人物/礼赠场景。不要求恰好140字符，不以无关词或生硬短语凑数。
- 避免“漂亮、精美、很好看”等主观形容词。通常优先1–2个有区分价值的客观属性，但这不是名词、用途词数量上限；重要信息可保留。默认不放不知名作者/品牌名和非关键尺寸；尺寸决定商品用途、适配或选购时可以保留。
- 标题与Tags优先互补：标签补充标题未覆盖的相关搜索短语。不是逐单词零重复，也不因字面不同就认定新增了购买意图。
- 描述开头约200字符内突出核心品类与真实商品价值；不是搜索排名阈值。素材来源及编辑记录放内部资料，买家文案不机械加入制作工具名称；默认不展开谁制作、如何制作等背景；已确认且支撑购买理由的工艺事实可简洁使用，确有适用的平台强制披露要求时按必要范围处理。

官方当前建议标题简洁、考虑少于15词，普通礼赠短语通常交给其他字段；这与本地的长标题偏好存在取舍。按用户已明确的方向出稿并保留可读性，不擅自缩短已确认标题，也不声称接近140字符或加入礼赠词必然提高排名。官方同时建议使用相关长尾标签；“优先核心词”不等于排除所有细分词。

### 已核实的字段约束

2026-10-22核对官方资料；日期是查证日期，不是规则生效日期。执行时核对当前界面/接口的适用情况。

| 字段 | 约束与性质 | 来源 |
|---|---|---|
| Listing标题 | 最多140字符；少于15词是建议 | [上架字段](https://help.etsy.com/hc/en-us/articles/115015628707-How-to-Create-a-Listing) |
| Tags | 最多13项，每项最多20字符；官方建议用满相关标签 | [标签](https://help.etsy.com/hc/en-us/articles/360000336307-How-to-Use-Tags-to-Get-Found-in-Search) |
| ALT | 官方指导简洁描述，至多250字符；不采用旧项目125字符默认 | [ALT](https://help.etsy.com/hc/en-us/articles/4406604492823-How-to-Add-a-Text-Alternative-to-Your-Listing-Images) |
| 新版个性化问题 | `question_text`为1–45字符；适用问题类型的`instructions`最多120字符，dropdown不填说明 | [个性化迁移](https://developer.etsy.com/documentation/tutorials/personalization-migration/) |

个性化新版最多5个问题，支持文本、选项、上传类型，按实际需要生成。内部按问题类型记录标题，以及适用的说明、下拉选项或上传标签；dropdown 不记录 `instructions`。已有`personalization.title`、`personalization.description`可沿用作单个文本或上传问题填写稿的兼容字段；它们不是官方API字段，不能据此覆盖既有多个问题。买家输入上限、商品制作容量与文案分开记录。适用标题/说明还须符合当前接口的开头与大小写约束；不能只验长度。普通变体选项长度不得从个性化dropdown的限制推导。

## 关键词证据与分配

沿用产品定义中的调研选择。已跳过调研时，直接按商品事实及用户方向整理相关词，热度标为未验证，不主动查询市场数据或要求补研究；只查关键词时不扩展到定价或定位研究。必要的平台字段规则查证不属于市场调研。

- 热度依赖真实可用数据，不靠模型给词打“高流量”标签。优先查询可访问的 Etsy Marketplace Insights；第三方工具数据标为其估算。Google Trends、Pinterest 和公开搜索只作趋势、表达及供给参考，不冒充 Etsy 站内搜索量。
- 记录关键词、来源、目标市场、数据周期/查询时间、实际指标、相关性和建议字段。指标缺失写“热度未验证”；不猜测数字，不要求用户为完成普通草稿必须购买工具。
- 先排除与商品无关的词，再比较购买需求、可比的需求与竞争数据、趋势和新增覆盖。gift/custom 等泛词的重合不能单独证明相关。未知竞争量不按 0 或 1 计算所谓机会分；不同来源和周期的数值不直接混排。
- 联合检查标题、Tags及实际已填的分类/属性。官方指出分类/属性可参与匹配，完全重复这些字段的标签通常无需再占位置；不据此推导“标题与Tags重复会受罚”。分类未知时不能假定它已覆盖某词。
- 分配短语时仅应用当前店主已确认的偏好；适用上述互补偏好时，在内部资料简记各标签新增的表达或意图。词形不同不等于更多流量；同义词可以帮助覆盖不同表达，但不能谎称覆盖了不同商品用途。
- 节日词须适合商品与目标市场；不为填名额硬套节日，也不因使用节日词追问物流信息或许诺赶上节日。ALT如实描述已有画面，不能为去季节词歪曲图片。

## 各字段写法

### 标题

- 当前店主已确认上述标题偏好时，按清晰品类 → 关键差异 → 其他有用的相关用途/购买信息组织；其他店主按其已确认偏好和商品事实组织。重要信息前置服务手机端阅读，不宣称前40–60字符存在排名权重阈值。
- 同一标题不反复堆叠相同短语；保留自然语法，不靠删除介词来实现零重复。同义产品词必须准确，不能为了换词变成另一种商品。
- 价格、运费和促销使用对应字段，不塞进标题；不将这条写作建议泛化成“平台禁止包邮或优惠”。出稿时计算实际复制文本长度。

### Tags

- 目标用满13个相关标签，每项遵守已核实限制；候选不足时先扩展真实同义词与适用场景，仍不足则注明未满，不捏造商品特征、收礼人或用途。多词自然短语优先，确实是独立品类的单词也可使用。
- 当前店主已确认标题与Tags互补偏好时，优先选择标题未覆盖的相关核心品类与用途，再补充相关人物/场景或有区分价值的细分表达。不固定配额，也不把一件商品的词表套给其他品类。例如需要覆盖`phone charm`时，不默认只用`bamboo phone charm`代替；标题已覆盖该核心短语时，标签优先交给其他有效入口。不能只因某标签出现在标题里就自动删除，先确认是否有更相关的补充词可替换。
- 有口径可比的 Etsy 需求数据时，在相关性成立的候选词中优先评估更大搜索需求的核心词；无数据时仍先覆盖核心词，但只记录这是选词策略，搜索量未验证。不凭词长推断搜索量差几个量级，也不因竞争高就机械避开核心词。
- 核心词与细分词共同评估相关性、可用需求数据及购买意图；不因长尾词搜索量较小就一律删除。人物/礼赠词须与目标买家和使用情境相符，“任何人都能收到”不足以给每件商品塞满男女、亲友及各类节日标签。
- 人物＋场景的长短语超过20字符时，拆成仍能独立理解的自然短语，例如 `graduation gift` 与 `gift for boyfriend`，或 `birthday gift` 与 `gift for husband`。逐项计数，不截断单词，也不退化为一组无意义的单词标签；拆分不等于已验证完整短语的搜索量或精确匹配效果。
- 检查标签组内完全重复、大小写/单复数/词序变换的近似重复，以及跨字段短语重复。组内重复与跨字段重合分开判断，不为避开共用单词改用生硬或极细分表达。默认输出本次整组标签，以半角逗号连接；用户只要变更项时另外标明。
- Tags与标题使用店铺对应的语言/翻译字段，不在同一组混塞多语、故意拼错或用单复数占多个位置；字符合法性按当前官方规则检查。

### 描述

- 开头自然结合核心商品词与实际价值，不照抄标题或堆积搜索词；关键的尺寸/适配条件不能为开头版式而隐去。不强制套问句或固定模板。
- 正文围绕买家的购买判断组织：商品是什么、有什么具体价值、适合哪些真实场景、收到什么、如何选择或提交定制内容。按需写清交付内容、选项、买家定制步骤、材料尺寸和已确认的包装信息，不强制套齐章节。默认不写物流、制作周期或制作背景，也不将这些缺失列为待补项；售后等经营承诺仅在用户要求且已有确认资料时引用。非定制商品跳过定制；确认字词与确认排版是两项不同服务，不能混写。
- 吸引力来自具体且可信的价值：将商品特点连接到买家的使用体验、表达需求或礼赠意义；避免只罗列规格、空泛赞美或制造紧迫感。短段落与必要列表便于扫读，买家能快速找到选项区别和下单所需信息。
- 文化祝福可以解释寓意，不承诺好运、医疗或疗愈效果。材料只写真实物理材料，不把用途、SEO 词、丝绸质感写成真实材质。
- 有同店资料时突出本商品区别；不为区别而替换准确品类词，也不声称同词开头必然造成搜索蚕食。

### 变体与预设

- 使用适用于该字段和当前后台的已核实约束；字符计数包含编号和空格。旧任务的20字符选项限制不能无条件推广到所有变体字段。
- 预设按真实可提供的选项设计，文字长度依商品版面和用户选择；普通实物变体无需强加编号。多项文案/图案需要对照时用稳定编号关联选项与图稿。
- 对中文文案预设，买家须能从选项、图与描述知道实际书写内容；能放下时可用“编号＋中文”，放不下时可只用编号并提供对应表。
- 英文主题名、意译与中文原句分别记录。古典出处需核实，现代句不冒认古人；英文引申不冒充逐字翻译。定稿前检查实际书写区域能否承载文字。

### 图片与 ALT

- ALT首先服务盲人及低视力买家理解图片，也可能有助于站外搜索。自然说明商品及本图独有的细节、尺度、布局和关键文字；不强制每条以同一品类/定制关键词开头，不把它当额外Tags栏。
- 实际查看每张图，再写对应的英文 ALT；说明区别、颜色、布局和关键图中文字，不照抄标题，不批量复用、不以空泛 image of 起句，不堆热词。
- 遵守已核实的ALT长度指导；复杂信息图保留关键含义，并在描述提供完整对应内容。
- 测量真实文件像素和格式，区分原图、合成预览、AI 增强和最终可上传素材。不能将预览称为未经修改的实拍，不能把放大等同恢复细节。图片要求依当前官方资料核对，不照搬旧缓存数字或格式列表。
- 品牌/IP 可疑内容要求核实依据，不因词表命中直接认定侵权；只在与商品有关时检查，不输出泛化合规清单。

### 后台属性

依据用户实际截图及商品事实逐项映射属性。区分材质与颜色、外轮廓与表面图案、结构功能与普通使用动作；不适用项留空或选明确的否定值。下拉选项未展示时用条件建议，不编造当前可选项。具体商品的选值存商品资料，不固化到通用技能。
